## Troubleshooting Installation

### Issue: ModuleNotFoundError
**Solution**: Ensure Python path includes incident_intelligence directory
```python
import sys
sys.path.insert(0, '/path/to/incident_intelligence')
```

### Issue: Wrong Python version
**Solution**: Check Python version
```bash
python --version  # Must be 3.8+
```

### Issue: Missing standard library
**Solution**: Reinstall Python - standard libraries should be included
```bash
python -m pip install --upgrade python
```
